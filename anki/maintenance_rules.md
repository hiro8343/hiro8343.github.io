# 🧠 楽しい暗記サイト・メンテナンスマニュアル

このドキュメントは、本サイトの機能追加、コンテンツ修正、デザイン変更時に「整合性」を保つための連動ルールをまとめたものです。

---

## 🛠️ 機能追加・変更時のチェックリスト

### 1. 新しいゲーム・コンテンツを追加した時
新しい暗記モードや学習用ページを作成した際は、以下のファイルを必ず更新してください。

- [ ] **index.html**: 「エリア案内」のカードとして追加し、適切なアイコンとキャッチコピーを設定する。
- [ ] **guide.html (暗記サイトの歩き方)**: 「Step 02: ゲームモードを攻略する」に新しいカードを追加し、遊び方と狙いを1,500文字程度のボリューミーな解説で記述する。
- [ ] **mypage.html (記録システム)**: 新しいゲームのスコアや結果を `UserData` (scripts/user_data.js) に保存・表示するためのロジックを確認/追加する。
- [ ] **about.html**: 必要に応じて「このサイトでできること」のリストに追記する。

### 2. 暗記データ（スプレッドシート/JSON）を修正した時
暗記対象のタイトルやカテゴリ名を変更した際は、以下の箇所に影響が出ます。

- [ ] **URLパラメータの一致**: `quiz_game.html?title=◯◯` などのリンク先が、新しいタイトルと完全一致しているか。
- [ ] **表記の整合性**: ボタン名やリンクテキストと、遷移先ページのタイトル（H1）が完全に一致しているか。ユーザーが迷わないように統一する。
- [ ] **依存関係の確認**: `cool.html` (コレクション) と `quiz_game.html` (クイズ) など、同じデータを参照している複数のページで整合性が取れているか。

### 3. 暗記ノベル「10万点の特異点」を更新した時
新エピソードを執筆した際は、以下の作業を行います。

- [ ] **story.html**: 新しい章を追加し、アンカーリンクを設定する。
- [ ] **index.html**: 最新エピソード公開中のバナーやキャッチコピーを更新し、鮮度を保つ。

## 🎨 デザイン・UIの統一ルール

- **アクセントカラー**: `main.css` で定義されている色（Cyan, Pink, Purple, Green）を意味付けに応じて使い分ける。
- **アニメーション**: `animations.css` の `animate-fade-in` や `animate-pop-in` を使用し、ページ遷移時に一貫した「動き」を持たせる。
- **SEO対策**: 
    - 各ページに必ず一つの `<h1>` を置く。
    - 独自性の高いテキストコンテンツを常に優先する（静的テキストを増やす）。

## 🚀 デプロイとGitHub管理

- **二重リモートの注意**: 
    - `origin`: 開発用リポジトリ (tanoshiianki)
    - `publish`: 公開用リポジトリ (hiro8343.github.io)
    - 公開時は必ず `git push publish main` を実行する。
- **バックアップ**: 大規模な修正前にはファイルを `.bak` 保存するか、Gitのコミットメッセージで修正内容を詳細に記録する。
